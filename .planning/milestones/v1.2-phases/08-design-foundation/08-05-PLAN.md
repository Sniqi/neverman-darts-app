**Sweep Rules — apply to every file in this plan (same rules as 08-03/08-04-PLAN.md, restated here since this plan may run independently):**
1. **Color substitution.** Replace every hardcoded hex/rgba using this table: `#111318`→`var(--bg)`, `#1e2027`→`var(--surface)`, `#262932`/`#2d2d2d`→`var(--surface-2)`/`var(--surface-3)`, `#e8a020`/`#f0ab2c`→`var(--accent)`, `#f0f0f0`→`var(--text)`, `#888`→`var(--text-muted)`, `#c0392b`→`var(--destructive)`. For chart-specific colors (bar fills, trend lines, axis text) with no exact DS match, map to the nearest DS token by role (your discretion per CONTEXT.md) — e.g. an accent-colored trend line uses `var(--accent)`, a muted axis label uses `var(--text-muted)`, a chart gridline uses `var(--line)`.
2. **Text-on-accent-fill pairing.** Any element whose background becomes `var(--accent)` AND whose own text color was the old bg-hex (`#111318`) becomes `background: var(--accent); color: var(--on-accent);` — not `var(--bg)`. This applies to `src/routes/+page.svelte`'s `.menu-btn--accent` (currently `background: #e8a020; color: #111318;`).
3. **Fallback cleanup.** Drop the second argument of every `var(--token, #hexfallback)` (e.g. `var(--accent, #e8a020)` → `var(--accent)`).
4. **Radius sanity-check.** Old scale was 8/12/16px for sm/md/lg; new scale is xs=8/sm=12/md=16/lg=20/pill=999. `src/routes/+page.svelte`'s `.menu-btn` currently hardcodes `border-radius: 8px` with no var() — per role (menu buttons = "buttons" role), this becomes `var(--radius-sm)` (12px). For existing `var(--radius-*)` call sites in match/+page.svelte and display/+page.svelte, keep the same token name if the DS's new larger size is intended for that role, otherwise shift down one tier.
5. **Motion retiming (general rule).** Round durations to the nearest DS token: ≤125ms→`var(--dur-fast)`, 126-175ms→`var(--dur-base)`, 176-250ms→`var(--dur-med)`, 251-300ms→`var(--dur-slow)`. Replace the easing keyword with `var(--ease)`. No file in this plan has a locked motion-duration exception — display/+page.svelte's `fadeIn`/`fadeInExit` keyframes are NOT among the four CONTEXT.md-named exceptions (shake/score-float/liveRowPulse/zeroFlashFade), so they follow this general rule.
6. **Score numerals.** StatCard's value display gets `font-family: var(--font-score); font-variant-numeric: tabular-nums;` per CONTEXT.md's named component list.
7. **No chart rebuild.** AverageTrendChart, DartsPerLegChart, and ScoreDistributionChart are bespoke inline-SVG components — swap their hardcoded colors for `var(--token)` equivalents only. Do not restructure the SVG markup, change chart types, or add new visual elements — that is explicitly out of scope for this entire milestone (REQUIREMENTS.md "Out of Scope": "Rebuilding stats charts as DS primitives").

Output: 12 swept files, zero hardcoded colors remaining, no functional change.
