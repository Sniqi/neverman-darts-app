Sweep the scoring-input, dialog, and overlay/toast component families — 15 files — replacing every hardcoded color with the DS token equivalent, retiming transitions/keyframes to the DS duration scale (with the two locked exceptions in this group: Numpad's shake, PauseOverlay's zeroFlashFade), sanity-checking radius token call sites against the new pixel values, and applying `--font-score` + `tabular-nums` to the two named score-bearing surfaces in this group (ScorePanel, Numpad).

Purpose: FOUND-01 (zero provisional colors), FOUND-03 (DS spacing/radii/elevation), FOUND-04 (DS motion scale + the two CONTEXT.md-resolved motion exceptions), FOUND-02 (tabular-nums score styling).

**Sweep Rules — apply to every file in this plan (per CONTEXT.md "Specifics" + PATTERNS.md "Old→new provisional color map" + "Component sweep" sections):**
1. **Color substitution.** Replace every hardcoded hex/rgba (in both `<style>` blocks and inline `<script>` color assignments, e.g. Dartboard's SVG fill logic) using this table: `#111318`→`var(--bg)`, `#1e2027`→`var(--surface)`, `#262932`/`#2d2d2d`→`var(--surface-2)`/`var(--surface-3)`, `#e8a020`/`#f0ab2c`→`var(--accent)`, `#f0f0f0`→`var(--text)`, `#888`→`var(--text-muted)`, `#c0392b`→`var(--destructive)`, `#444`/`#444444`→`var(--board-stroke)` or `var(--line-strong)` by context, `#1a5c2e`→`var(--board-green)`, `#8b1a1a`→`var(--board-red)`. Anything not on this table maps to the nearest DS token by role (your discretion per CONTEXT.md — text/muted/surface-step/line).
2. **Text-on-accent-fill pairing.** Any element whose background becomes `var(--accent)` AND whose own text/foreground color was the old bg-hex (`#111318`) is a text-on-accent-fill pair: the text color must become `var(--on-accent)` (#191104), NOT `var(--bg)` — `var(--bg)` and `var(--on-accent)` are different tokens that happened to look similar under the old palette.
3. **Fallback cleanup.** Drop the second argument of every `var(--token, #hexfallback)` entirely (e.g. `var(--accent, #e8a020)` → `var(--accent)`) — `:root` always defines every token now, so the fallback is dead code carrying a banned literal.
4. **Radius sanity-check.** For existing `var(--radius-sm|md|lg)` call sites: old scale was 8/12/16px for sm/md/lg; new scale is xs=8/sm=12/md=16/lg=20/pill=999. If the DS's new larger size for that role is intended (buttons/keys/chips/inputs use --radius-sm=12px; cards/score-cards/list-containers use --radius-md=16px; dialogs/sheets use --radius-lg=20px), keep the same token name. If an element must stay at its old pixel size, shift down one tier (e.g. old `var(--radius-sm, 8px)` on something that must stay 8px becomes `var(--radius-xs)`). For hardcoded pixel radii with no var() at all (e.g. Numpad's `border-radius: 6px`), map by DS role: Numpad's keys/input-display/confirm-key are exactly the "buttons, keys, chips, inputs" role → `var(--radius-sm)` (12px).
5. **Motion retiming (general rule).** Round existing transition/animation durations to the nearest DS token: ≤125ms→`var(--dur-fast)`(100ms), 126-175ms→`var(--dur-base)`(150ms), 176-250ms→`var(--dur-med)`(200ms), 251-300ms→`var(--dur-slow)`(300ms). Replace the easing keyword with `var(--ease)` for standard transitions; use `var(--ease-spring)` only for ConfirmDialog's dialogIn pop. Apply `--press-scale` (`scale(.97)`) to existing `:active` states that currently only toggle opacity/background — do not build the full Phase-9 Button gradient/sheen treatment.
6. **Locked motion exceptions in THIS plan** (per CONTEXT.md "Motion & Sweep Ambiguities — Resolved"): Numpad's `shake` keyframe stays a literal `400ms` (not compressed to `var(--dur-slow)`), paired with `var(--ease)` for the easing. PauseOverlay's `zeroFlashFade` keyframe is NOT a documented DS exception — retime its `800ms` to `var(--dur-slow)` (300ms).
7. **Score numerals.** ScorePanel and Numpad's digit/entry display elements get `font-family: var(--font-score); font-variant-numeric: tabular-nums;` per CONTEXT.md's named component list.

Output: 15 swept .svelte files + 1 updated test file, zero hardcoded colors remaining.
