**Sweep Rules — apply to every file in this plan (same rules as 08-03-PLAN.md, restated here since this plan may run independently):**
1. **Color substitution.** Replace every hardcoded hex/rgba using this table: `#111318`→`var(--bg)`, `#1e2027`→`var(--surface)`, `#262932`/`#2d2d2d`→`var(--surface-2)`/`var(--surface-3)`, `#e8a020`/`#f0ab2c`→`var(--accent)`, `#f0f0f0`→`var(--text)`, `#888`→`var(--text-muted)`, `#c0392b`→`var(--destructive)`, `#444`/`#444444`→`var(--line-strong)` by context. Anything not on this table maps to the nearest DS token by role (your discretion per CONTEXT.md).
2. **Text-on-accent-fill pairing.** Any element whose background becomes `var(--accent)` AND whose own text color was the old bg-hex (`#111318`) becomes `background: var(--accent); color: var(--on-accent);` — not `var(--bg)`.
3. **Fallback cleanup.** Drop the second argument of every `var(--token, #hexfallback)` (e.g. `var(--accent, #e8a020)` → `var(--accent)`).
4. **Radius sanity-check.** Old scale was 8/12/16px for sm/md/lg; new scale is xs=8/sm=12/md=16/lg=20/pill=999. Keep the same token name if the DS's new larger size for that role is intended (cards/list rows/panels use --radius-md=16px); shift down one tier if the element must stay at its old pixel size.
5. **Motion retiming (general rule).** Round durations to the nearest DS token: ≤125ms→`var(--dur-fast)`, 126-175ms→`var(--dur-base)`, 176-250ms→`var(--dur-med)`, 251-300ms→`var(--dur-slow)`. Replace the easing keyword with `var(--ease)`. Apply `--press-scale` to existing `:active` states only — do not build the Phase-9 Button treatment.
6. **Locked motion exception in THIS plan:** PlayerPanel's `liveRowPulse` keyframe stays a literal `1.6s ease-in-out infinite` (per CONTEXT.md — continuous/ambient live indicator, not a one-shot interactive transition). No other file in this plan has a locked exception.
7. **Score numerals.** PlayerPanel's score-displaying elements get `font-family: var(--font-score); font-variant-numeric: tabular-nums;` per CONTEXT.md's named component list ("display surfaces").

Output: 14 swept .svelte files, zero hardcoded colors remaining.
