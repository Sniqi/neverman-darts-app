    Create `src/styles/components.css`. Write the shared button system first: a `.btn` base rule — `display:flex; align-items:center; justify-content:center; width:100%; border:none; cursor:pointer; font-family:var(--font-ui); text-align:left; gap:var(--space-sm); transition: transform var(--dur-base) var(--ease), background var(--dur-base) var(--ease), filter var(--dur-base) var(--ease); -webkit-tap-highlight-color:transparent;` and `.btn:disabled { opacity:.4; cursor:default; }`.

    Then the five DS variants, each with its own `:active` rule using `transform:scale(var(--press-scale))` plus `filter:brightness(1.1)` on filled variants (menu/accent/cta), matching the codebase's established CSS-`:active` idiom (per RESEARCH Pattern 1 — do NOT introduce Button.jsx's JS pointerdown/up handlers):
    - `.btn--menu`: `justify-content:space-between; height:var(--row-h); padding:0 var(--space-lg); background:var(--surface); color:var(--text); border:1px solid var(--line); border-radius:var(--radius-sm); font-size:var(--text-md); font-weight:500; box-shadow:var(--edge-highlight);`. Add `.btn--menu svg { width:20px; height:20px; opacity:.7; flex-shrink:0; }` so existing 16px chevron SVGs in usage sites resize to the DS 20px/opacity-.7 spec without touching each file's markup (CSS width/height override the SVG's HTML width/height attributes).
    - `.btn--accent`: `height:var(--row-h); padding:0 var(--space-lg); background:linear-gradient(180deg, var(--accent-bright) 0%, var(--accent) 45%, var(--accent-deep) 130%); color:var(--on-accent); border-radius:var(--radius-sm); font-size:var(--text-md); font-weight:600; box-shadow:var(--shadow-raise), inset 0 1px 0 rgba(255,255,255,.25);`.
    - `.btn--cta`: `min-height:var(--row-h); padding:var(--space-sm) var(--space-lg); background:` the same gradient string as accent; `color:var(--on-accent); border-radius:var(--radius-sm); font-size:var(--text-lg); font-weight:700; letter-spacing:.01em; box-shadow:var(--shadow-raise), inset 0 1px 0 rgba(255,255,255,.25);`.
    - `.btn--destructive`: `height:56px; background:var(--destructive); color:#fff; border-radius:var(--radius-sm); font-size:var(--text-md); font-weight:600; box-shadow:inset 0 1px 0 rgba(255,255,255,.15);`; its `:active` uses `opacity:var(--press-opacity); transform:scale(var(--press-scale));` (matches the existing `ConfirmDialog.svelte` idiom exactly).
    - `.btn--cancel`: `height:56px; background:var(--surface); color:var(--text); border:1px solid var(--border-input); border-radius:var(--radius-sm); font-size:var(--text-md); font-weight:600;`; `:active` sets `background:var(--surface-3); transform:scale(var(--press-scale));`.

    Then three discretionary extension classes (per CONTEXT.md "Claude's Discretion" — non-DS shapes, RESEARCH Assumptions A1/A2/A3):
    - `.btn--ghost`: `background:transparent; border:none; color:var(--text-muted);` (no width/height — inherits `.btn` base's 100% width for full-width ghost rows; icon-only usages combine this with `.btn--icon` below). `:active` uses `opacity:var(--press-opacity); transform:scale(var(--press-scale));`.
    - `.btn.btn--icon` (two-class selector so it reliably overrides `.btn--ghost`'s inherited width regardless of source order): `width:var(--hit-min); height:var(--hit-min); padding:0; flex-shrink:0;` — a fixed 48x48 square hit target for icon-only buttons.
    - `.btn--surface`: `height:56px; background:var(--surface); color:var(--text); border:none; border-radius:var(--radius-sm); font-size:var(--text-md); font-weight:500;`; `:active:not(:disabled)` sets `background:var(--surface-3);`.
    - `.btn--destructive-outline`: `height:56px; background:transparent; border:1px solid var(--destructive); color:var(--destructive); border-radius:var(--radius-sm); font-size:var(--text-md); font-weight:600;`; `:active` sets `background:var(--destructive-soft); transform:scale(var(--press-scale));`.

    Finally add the shared custom switch (COMP-02, transcribed verbatim from `design/components/core/ToggleRow.jsx` per RESEARCH Pattern 2 — this is consumed by Plan 09-05 and 09-07, not by this plan's own tasks): `.switch { position:relative; width:56px; height:34px; flex-shrink:0; background:var(--surface-3); border:1px solid var(--line-strong); border-radius:var(--radius-pill); cursor:pointer; padding:0; transition: background var(--dur-med) var(--ease), border-color var(--dur-med) var(--ease); box-shadow: inset 0 1px 3px rgba(0,0,0,.35); -webkit-tap-highlight-color:transparent; }`, `.switch.on { background:var(--accent); border-color:var(--accent); box-shadow:var(--glow-accent); }`, `.switch .thumb { position:absolute; top:3px; left:3px; width:26px; height:26px; border-radius:50%; background:var(--text-muted); transition: transform var(--dur-med) var(--ease-spring), background var(--dur-med) var(--ease); box-shadow:0 1px 3px rgba(0,0,0,.4); }`, `.switch.on .thumb { background:var(--on-accent); transform:translateX(22px); }`.

    Wire it in: in `src/app.css`, add `@import './styles/components.css';` as the 6th line, immediately after the existing `@import './styles/fonts.css';` line (before the `* { box-sizing: border-box; }` rule).
  </action>
