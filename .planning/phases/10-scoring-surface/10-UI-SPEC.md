# Phase 10 — UI Design Contract

> Visual and interaction contract for `/match` scoring surface. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **This is a transcription phase, not greenfield.** The DS (`design/components/scoring/*.jsx` + `.prompt.md`) is the literal source of truth. Values below are copied from those files and from the already-shipped tokens (Phase 8) — the executor's job is to make `src/ui/input/*.svelte` match them exactly while keeping scoring behavior byte-identical (SCOR-01..04).

## Design System

| Property | Value |
|----------|-------|

Do not conflate the two notations — VisitStrip's own slot cells (if kept as plain-text buttons rather than migrated to `<DartPill>`) use the long form; embedded `<DartPill>` components use the short form. Confirm during planning which of the two `VisitStrip` renders this app already uses (plain-text cells per current `src/ui/input/VisitStrip.svelte`) and keep using the long-form notation for that surface, since CONTEXT.md's locked strings (`Bull (50)`, `Bull (25)`, `✕`) are the long form.

## Component Contracts (SCOR-01..04) — transcribed from `design/components/scoring/*`

### Numpad (SCOR-01)
- Layout: `7 8 9 / 4 5 6 / 1 2 3 / C 0 ⌫`, full-width "Bestätigen" below, 3-column grid, `--space-sm` gaps.
- Key: height `--key-h` (76px), `min-width: 64px`, bg `--surface`, `1px solid --line-strong`, radius `--radius-sm` (12px), `--edge-highlight` shadow, digits 32px/500 `--font-ui` tabular-nums.
- Pressed state: bg steps to `--surface-3`, `transform: scale(var(--press-scale))` (0.97), on `pointerdown`/cleared on `pointerup`/`pointerleave`; transition `var(--dur-fast) var(--ease)`.
- Entry display: height `--key-h`, bg `--bg-deep`, 2px border `--line-strong` (→ `--destructive` when invalid), 40px/700 `--font-score`, `inset 0 2px 6px rgba(0,0,0,.35)`; shows `—` when empty.
- Invalid: border+text → `--destructive`, shake keyframe ±6px over 400ms (LOCKED — do not change duration), "Ungültige Punktzahl" message 15px/500 `--destructive` beneath.
- "C" key: text `--destructive`, 26px/600. "⌫" key: 26px, `aria-label="Letzte Ziffer löschen"` (redeem Phase-8-deferred a11y item).
- "Bestätigen": height `--key-h`, full width, `linear-gradient(180deg, --accent-bright 0%, --accent 45%, --accent-deep 130%)`, text `--on-accent`, 22px/700, `--shadow-raise` + inner sheen `inset 0 1px 0 rgba(255,255,255,.25)`.
- Scoring logic unchanged: max 3 digits, ≤180, existing `isValidVisitTotal` validation — visuals only.

### Dartboard (SCOR-02)
- ONLY color/flash values move to tokens (see color tables above) — polar hit detection (`getScreenCTM().inverse()`, Pythagoras for ring, `atan2` for segment), the 20-segment order, and all enlarged ring radii (`R_INNER_BULL 30 / R_OUTER_BULL 74 / R_INNER_SINGLE 150 / R_TRIPLE_END 200 / R_OUTER_SINGLE 290 / R_DOUBLE_END 340 / R_MISS_OUTER 400`, `viewBox="-200 -200 800 800"`) stay byte-identical.
- Number labels + ring dividers keep `pointer-events: none` so taps always fall through to scoring paths.
- Active-touch feedback: tapped region/ring flashes 300ms (see flash-overlay colors above), score label floats up from tap point over 1.6s via `db-float`/`score-float` keyframe (LOCKED duration/easing: `cubic-bezier(.25,.46,.45,.94)`), floating text uses per-hit color table above with dark stroke halo (`paintOrder: stroke`, `stroke rgba(0,0,0,.75)` width 4) for legibility over any segment color.
- Proof gate: existing dartboard hit-detection unit/E2E tests stay green unmodified.

### VisitStrip & DartPill (SCOR-03)
- VisitStrip container: `--space-sm` gaps, `--space-xs --space-md` padding, radius `--radius-md`; bust state tints bg `--destructive-soft` + `inset 0 0 0 1px --destructive-line` (transition `--dur-slow`).
- Each slot: height `--control-h` (56px), flex 1, `min-width: 80px`, filled bg `--surface-2` / empty `--surface`, filled border `1px solid --line-strong` / empty `1px dashed --line-strong`, radius `--radius-sm`, filled text `--text` / empty `--text-faint`, radius-pill NOT applied to the slot itself (slot is `--radius-sm`; `--radius-pill` (999) applies to the `<DartPill>` element when/if rendered inside).
- Tap-to-undo unchanged: disabled when no darts thrown, `onclick` fires undo regardless of which slot tapped (existing behavior).
- Notation: apply the LOCKED strings from the Dart Notation Contract above (`Bull (50)`, `Bull (25)`, `✕`) to whichever helper this app's VisitStrip actually renders text through.
- DartPill (if/where used standalone, e.g. inside slots or elsewhere on this surface): radius `--radius-pill`, padding `.12em .55em`, 18px/600; triple + both bull variants → color `--accent` / bg `--accent-soft` / border `--accent-line`; double → color `--accent-double` (`#f6dfae`) / translucent amber bg+border via `color-mix`; miss → color `--text-faint`, dashed `--line-strong` border; bust → color `color-mix(in oklab, var(--destructive) 75%, white)`, bg `--destructive-soft`, border `--destructive-line`, `text-decoration: line-through`.
- Triple flash/glow color is `--triple` (`#ff7d75`) — same token used for the Dartboard's triple/inner-bull float labels.

### ScoreCard & Verification (SCOR-04)
- Card: `flex:1`, `min-width:150px`, padding `--space-md --space-lg`, radius `--radius-md`.
- Active: bg `linear-gradient(--accent-soft, --accent-soft), --surface-2`, border `1px solid --accent-line`, `box-shadow: inset 4px 0 0 --accent, --glow-accent, --edge-highlight`. Inactive: bg `--surface`, border `--line`, shadow `--edge-highlight` only.
- Name: 22px/600, `--text` active / `--text-soft` inactive, ellipsis-truncate, no wrap.
- Remaining score: `--font-score` tabular-nums, `--tracking-tight`; active 96px/800 with amber text-shadow glow; inactive 44px/700, no glow. Transition `font-size var(--dur-med)` when active state changes.
- Checkout pill (only rendered when active AND a checkout route exists): 17px/700, color `--accent`, bg `--accent-soft`, border `--accent-line`, radius `--radius-pill`, padding `4px 14px`, plus `--glow-accent` box-shadow (discretion addition, see Color section above). Renders nothing when no suggestion (existing D-12 behavior unchanged).
- Legs/Sets caption: 17px, label weight 500 `--text-muted`, numeric value weight 700 `--text`, tabular-nums. Sets shown only when `setsEnabled`.
- BUST: existing red flash keyframes keep their current token-based durations (CONTEXT.md LOCKED) — only the color values move fully onto `--destructive`/`--destructive-soft`/`--destructive-line` tokens; no new timing.
- Gate: 535 Vitest + 9/9 Playwright green; scoring behavior (state transitions, checkout math, bust detection) is EXACTLY unchanged — this is a pure visual pass.
