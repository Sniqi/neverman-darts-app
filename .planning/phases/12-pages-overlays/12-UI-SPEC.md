# Phase 12 — UI Design Contract

> Visual and interaction contract for the app's remaining pages (start hub, setup, history list/detail, stats dashboard, data/backup) and global overlays/toasts (PauseOverlay, RecordOverlay, MatchWinOverlay, ReloadPrompt, ResumeToast). Generated by gsd-ui-researcher, verified by gsd-ui-checker.
> **This is a transcription phase, not greenfield.** `design/templates/darts-app/screens.jsx` (layout literals), `design/components/history/HistoryRow.jsx` + `.prompt.md`, and `design/readme.md` (overlay/toast prose) are the source of truth. The tables below diff those DS literals against the **currently shipped** Svelte files so the executor sees exactly what must change vs. what's already correct. All behavior stays identical (PAGE-04 gate: auto-pause countdown logic, record celebration triggers, PWA update flow, Cast resume signal — zero logic changes, CSS/markup-only). Stats charts are **recolor-validation only — REBUILD FORBIDDEN** (REQUIREMENTS Out of Scope table).

## Design System

| Property | Value |
|----------|-------|
| Tool | none — hand-authored Svelte components + CSS custom-property tokens (no shadcn/Radix/Base UI in this project) |
| Preset | not applicable |
| Component library | none (bespoke); shared primitives from Phase 9: `.btn` variants (`--cta`/`--accent`/`--menu`/`--ghost`/`--surface`/`--destructive`), `.switch`, `.chip`, `.seg-btn`, `.stepper-*` |
| Icon library | none — inline stroke SVG (chevron-right/left, info circle) 20–22px `viewBox="0 0 24 24"` `stroke-width="2"` + Unicode glyphs (▼ collapsible, × remove, − / + steppers). No emoji. |
| Font | `--font-ui` (Barlow) throughout these pages/overlays; `--font-score` (Barlow Semi Condensed) + `tabular-nums` only on numeric/result surfaces (HistoryRow's 2-player result, stat values, checkout numbers) |

Tokens already exist from Phase 8 (`--space-*`, `--text-*`, `--radius-*`, `--shadow-*`, `--backdrop`, `--blur-backdrop`, `--line*`) and Phase 9 (`.btn`/`.switch`/`.chip` primitives). This phase consumes them — it introduces no new tokens.
